VERSION 17 — 12 septembre 2026

Le token POLL_OAUTH est INVALIDE ("Invalid OAuth token"). Deux causes
possibles et comment je les ai corrigées / diagnostiquées :

1) Le token a "oauth:" collé devant, des espaces ou des guillemets.
   -> CORRIGE : le programme nettoie maintenant tout seul (il retire
   "oauth:", les espaces, les guillemets). Plus besoin de le refaire.

2) Le token est vraiment faux / expiré / mal copié.
   -> Dans ce cas il faut le REGENERER.

VERIFIE TOI-MEME :
Relance demarrer-pont.bat et regarde la ligne :
   "[auth] token lu : XX caractères, commence par \"XXXXXX...\""
Un token Twitch valide fait ~30 caractères (lettres + chiffres).

Si ça affiche encore "Invalid OAuth token", c'est que le token est faux :
regénère-le avec ce lien exact, puis colle UNIQUEMENT ce qui suit
access_token= (sans oauth:, sans espace, sans guillemets) :
