🔊 SON DANS OBS – REGLAGE OBLIGATOIRE

Si tu entends le son dans le panneau (TEST SON) mais pas dans OBS :

1. Dans OBS, clic droit sur ta source Navigateur (widget.html) → Propriétés
2. Coche Contrôler le son via OBS (ou "Control audio via OBS")
3. Dans le mélangeur audio OBS, la source Navigateur apparaît → mets-la en Monitoring et Sortie (ou au moins pas muette) et monte le volume
4. Dans OBS → Paramètres → Audio → Périphérique de monitoring → choisis ton casque/haut-parleurs
5. Assure-toi que l'URL OBS est http://localhost:8321/widget.html sans ?mute=1
6. Si toujours rien, clique une fois dans l'aperçu du navigateur OBS pour débloquer l'autoplay
